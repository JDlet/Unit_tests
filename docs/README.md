Все файлы с фигурами и тестами лежат в папке `Unit_tests`.

```text
labwork_4/

    ├── circle.py

    ├── square.py
    ├── triangle.py
    └── tests/
        ├── test_circle.py      # Тесты для круга
```

## Инструкция по запуску

### Запуск всех тестов сразу:

```bash
python3 -m unittest discover -s Unit_tests/tests -v
```

### Запуск тестов только для одной фигуры:

```bash
python3 -m unittest Unit_tests.tests.test_circle
```


## План тестирования

### 1. Цели и задачи тестирования

#### Цель: Проверить, что функции площади и периметра считают всё правильно.

#### Задачи: Написать тесты для каждой фигуры. Проверить обычные числа и ноль. Убедиться, что программа не выдает ошибок.

### 2. Описание тестируемого продукта

#### Это набор Python-файлов (circle.py, rectangle.py, square.py, triangle.py). В них есть функции area (площадь) и perimeter (периметр).

### 3. Область тестирования

#### Проверяю все 4 фигуры. Для каждой фигуры тестирую две функции: площадь и периметр. Отдельно проверяю граничные случаи (когда передается ноль) и дробные числа (для круга, где используется число Пи).

### 4. Стратегия тестирования

#### Использую функциональное тестирование (Unit-тесты). Пишу классы, наследуемые от unittest.TestCase. Внутри использую проверки self.assertEqual для целых чисел и self.assertAlmostEqual для чисел с плавающей точкой (чтобы не было ошибок из-за округления).

### 5. Критерии приемки

#### Работа сделана, если:
<mark>Все тесты проходят успешно (выводится OK).
Нет ни одной ошибки (FAILED или ERROR). </mark>

### 6. Ожидаемые результаты

<mark>В консоли должен появиться отчет, что все тесты пройдены (зеленый OK). </mark>
